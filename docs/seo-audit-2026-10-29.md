# Rightium SEO audit and launch corrections

Audited 29 October 2026 (Asia/Kolkata). Public origin: https://www.rightium.org.

## Scope and evidence

Rightium is a Bengaluru IP research service business with a publishing section.
The audit covered all 30 currently published routes: seven static pages, seven
service pages, 12 judgment analyses, and four condensed judgment studies. It
combined a public HTTP/HTML crawl, source review, CMS inspection, primary-source
research, and a 390px mobile article check. Private CMS records and backups are
excluded from Git.

Baseline: all 30 URLs returned HTTP 200 and had an H1, but every public page was
excluded by noindex. robots.txt blocked all crawlers. Every sitemap URL and
canonical pointed to the former rightium.in origin. The crawler found no broken
internal page links or in-page heading anchors. This is an observed crawl result,
not a promise that all historical or third-party URLs work.

## Implemented changes

| Priority | Issue | Correction |
|---|---|---|
| Critical | robots.txt, inherited metadata and HTTP headers each blocked production indexing | Public production is indexable; development and Vercel preview retain exclusion. The retired ALLOW_INDEXING value cannot silently block launch. |
| Critical | Canonicals, sitemap, Open Graph URLs and schema entities used rightium.in | Central public origin changed to https://www.rightium.org. Public contact email retained because a domain change does not establish a new mailbox. |
| High | Four condensed /work studies substantially duplicate their full /blog analyses | Canonicalize only judgment studies with matching published slug and title to their full articles; omit those duplicates from sitemap. Preserve unrelated original case studies. |
| High | Selected Work links existed only after opening a JavaScript modal | Render actual server-side anchors, retaining the normal-click modal and native modified-click navigation. |
| High | Word comparison tables lost column context during conversion | Preserve every column label, including distinctions between what a court held and what it did not hold, in all 16 documents. |
| Medium | Search titles were unnecessarily long and collection metadata described a different article set | Add concise CMS SEO title overrides without changing visible article titles; align the Insights index with the judgment collection. |
| Medium | Long contents lists precede the entire mobile article | Add native collapsible mobile article contents while keeping the desktop rail. |
| Medium | Below-fold article covers loaded eagerly | Add lazy loading and asynchronous decoding; retain intrinsic dimensions. |
| Medium | Limited contextual internal linking | Add two related analyses and a relevant patent-search service link per article. |
| Medium | Graham lacked a usable source citation | Add its official U.S. Reports record. |
| Low | Mayo's opinion PDF pointed to an entire volume | Link to the specific case PDF. |
| Low | Generic LinkedIn and X homepage links implied company profiles | Omit until verified business URLs are available. |
| Low | Structured data asserted an unsupported price band | Remove priceRange; retain truthful Organization/ProfessionalService, WebSite, BreadcrumbList and Article/BlogPosting markup. |
| Low | Image descriptions included generation implementation details | Use concise descriptions of the actual cover contents. All four covers remain GPT-generated. |

Production keeps noindex on admin, API JSON, draft-preview helpers and analytics
ingestion. Public media-file URLs are exempt from the API rule. Robots rules are
not authentication; existing CMS access controls remain necessary and unchanged.

The expected canonical sitemap has 26 URLs after consolidating four studies.
Those studies remain accessible to visitors and linked from the homepage.

## Performance and mobile

The inspected Alice article fits the 390px viewport without horizontal overflow.
The source already uses server-rendered copy, responsive homepage images, reserved
image dimensions, local font-display:swap fonts, reduced-motion support and an
offscreen-paused 3D scene with a static fallback. These are safeguards, not measured
Core Web Vitals results.

The PageSpeed Insights request returned HTTP 429. No valid Lighthouse score or
field LCP, INP or CLS measurement was obtained. Consequently a composite 0–100 SEO
health score is withheld: filling the skill's performance weight with an invented
value would misstate the evidence. Check Search Console/CrUX after sufficient
traffic exists. Field “good” thresholds at the 75th percentile are LCP <=2.5s,
INP <=200ms and CLS <=0.1. Further 3D/font tuning should follow a real trace.

## AI-search readiness

Public crawler access, readable server-rendered analyses, accurate entities,
source references, and sensible canonical consolidation are the relevant fixes.
No special AI markup or llms.txt is required for Google Search. OAI-SearchBot
controls OpenAI search crawling; GPTBot controls training crawling independently.
The general public robots rule permits crawling; it does not guarantee inclusion
or citation in any search or AI answer.

No new FAQPage or HowTo markup was added. Commercial FAQ content does not qualify
for Google's restricted FAQ rich results. No location doorway pages, fabricated
reviews, keyword-stuffed content or synthetic staff credentials were introduced.

## Validation and release

- SEO regression suite covers canonical origins, preview/draft exclusions,
  production crawlability, private headers, migration redirects and conditional
  duplicate consolidation.
- TypeScript and changed-file ESLint checks run before publishing.
- Production build and HTTP audit validate the public sitemap, H1s, unique titles,
  descriptions, canonical URLs, social images, JSON-LD, real 404s, redirects,
  crawlable case-study links, and private API noindex headers.
- Re-crawl the live site after Vercel deploys. A Git push alone does not establish
  that launch exclusions have been lifted.
- In Google Search Console, verify the www.rightium.org/domain property, submit
  https://www.rightium.org/sitemap.xml and inspect the homepage and representative
  articles. Search Console submission/access is not available in this session.
  Indexing and ranking are not guaranteed by a sitemap or robots change.

Completed validation: 10 SEO regression tests passed; TypeScript and changed-file
ESLint passed; the final CMS-connected production build succeeded; the production
HTTP audit passed all 26 canonical pages plus four linked study pages and sharing
images. Verified private API JSON retains noindex while public images do not.
At 390px, the article had no horizontal overflow and the native mobile contents
control opened and closed correctly. Verified the CMS retained all 12 published
analyses, concise SEO titles, related research links and corrected primary sources.
